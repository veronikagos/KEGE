Задание 6. Исполнитель черепаха
Варианты вопросов заданий

Обозначения фигур:
Фигура 1: s1 на s2
Фигура 2: s3 на s4
На оси абсцисс range(l1, r1)
На оси ординат range(l2, r2)

Кол-во точек в объединении (с учётом точек на линиях)
(s1 + 1) * (s2 + 1) + (s3 + 1) * (s4 + 1) - (r1 - l1) * (r2 - l2)

Кол-во точек в объединении (без учёта точек на линиях)
(s1 - 1) * (s2 - 1) + (s3 - 1) * (s4 - 1) - (r1 - l1 - 2) * (r2 - l2 - 2)

Кол-во точек в пересечении (с учётом точек на линиях)
(r1 - l1) * (r2 - l2)

Кол-во точек в пересечении (без учёта точек на линиях)
(r1 - l1 - 2) * (r2 - l2 - 2)

Периметр объединения
2 * (s1 + s2 + s3 + s4) - 2 * (r1 - l1 - 1 + r2 - l2 - 1)

Периметр пересечения
2 * (r1 - l1 - 1 + r2 - l2 - 1)

Площадь объединения
(s1 * s2 + s3 * s4) - (R1 - L1 - 1) * (R2 - L2 - 1)

Площадь пересечения
(R1 - L1 - 1) * (R2 - L2 - 1)

Команды Черепахи

Подключение всех методов модуля Черепаха
from turtle import *

Движение Черепахи вперёд относительно положения головы
forward(100) / fd(100)

Движение Черепахи назад относительно положения головы
backward(100) / bk(100)

Поворот Черепахи влево относительно положения головы
left(90) / lt(90)

Поворот Черепахи вправо относительно положения головы
right(90) / rt(90)

Поднять хвост
penup() / up()

Опустить хвост
pendown() / down()

Переносит Черепаху в заданные координаты
teleport(x, y)

Ставит точку в текущей позиции Черепахи размером size и цветом color
dot(size.color)

Задаёт размеры полотна Черепахи
screensize(10000, 10000)

Отключает анимацию
tracer(0)

Необходимо писать при наличии tracer
update()

Замораживает окошко Черепахи
done()
