Задание 6. Исполнитель Черепаха

Варианты вопросов заданий

Обозначения фигур:
Фигура 1: s1 на s2
Фигура 2: s3 на s4
На оси абсцисс range(l1, r1)
На оси ординат range(l2, r2)

Кол-во точек в объединении (с учётом точек на линиях)
(s1 + 1) * (s2 + 1) + (s3 + 1) * (s4 + 1) - (r1 - l1) * (r2 - l2)

Кол-во точек в объединении (без учёта точек на линиях)
(s1 - 1) * (s2 - 1) + (s3 - 1) * (s4 - 1) - (r1 - l1 - 2) * (r2 - l2 - 2)

Кол-во точек в пересечении (с учётом точек на линиях)
(r1 - l1) * (r2 - l2)

Кол-во точек в пересечении (без учёта точек на линиях)
(r1 - l1 - 2) * (r2 - l2 - 2)

Периметр объединения
2 * (s1 + s2 + s3 + s4) - 2 * (r1 - l1 - 1 + r2 - l2 - 1)

Периметр пересечения
2 * (r1 - l1 - 1 + r2 - l2 - 1)

Площадь объединения
(s1 * s2 + s3 * s4) - (r1 - l1 - 1) * (r2 - l2 - 1)

Площадь пересечения
(r1 - l1 - 1) * (r2 - l2 - 1)

Команды Черепахи

Подключение всех методов модуля Черепаха
from turtle import *

Движение Черепахи на step пикселей вперед относительно положения головы
forward(step) / fd(step)

Движение Черепахи на step пикселей назад относительно положения головы
backward(step) / bk(step)

Поворот Черепахи на step градусов вправо относительно положения головы
right(step) / rt(step)

Поворот Черепахи на step градусов влево относительно положения головы
left(step) / lt(step)

Поднять перо
penup() / up()

Опустить перо
pendown() / down()

Переносит Черепаху в заданные координаты
teleport(x, y)

Ставит точку размером size и цвета color в текущих координатах
dot(size, color)

Задает размеры полотна Черепахи
screensize(10_000, 10_000)

Отключает анимацию
tracer(0)

Необходимо писать при наличии tracer
update()

Замораживает окошко Черепахи
done()
